    Screenshot sources¶

    The current manual uses real native Windows captures from disposable GitHub Actions runners. They show controlled review data, not a user's LAN, real equipment availability or internet speed measurements. The retained November 20 captures predate the shared fixed headers, quiet Back controls, current Device Details tabs, shaded section headings and sidebar mode shortcut delivered on November 22. They still illustrate the recorded data and states, but are not exact current-layout references. No replacement capture was made during the documentation synchronization.

    Reproduce or replace¶

    Use disposable Windows CI, never a working user's desktop. Dispatch Pull request build on the intended immutable source with additional_scenarios selecting the main-page scenarios. Existing focused regression suites own their own fixtures, setup, readiness and cleanup; retrieve their artifacts for SQL results, imports, assignments, Settings and history. Enable documentation_showcase for the dedicated Devices and Room map fixture; its images and manifest appear in the existing UI-review artifact. Do not change assertions or fixture ownership simply to obtain a picture.

    Inspect each selected PNG and retain only the intended safe image. Record its actual source, run, artifact, dimensions, edits and visible state here and keep the page caption consistent. Commit the PNGs before artifacts expire. Newer screenshots alone do not prove that a feature has shipped.
