FingVibe 1.3 adds update checks and safe installer downloads from a compact Settings and About area, automatic local database backups, and a LAN peer checkpoint in network troubleshooting.
It also adopts the Connected home application icon with sharp small sizes and refines Devices, Device Details, Tools and Activity presentation while keeping each device's last known status steady between scans.

## Major changes

- **Updates and About:** About moves from Tools to Settings and shows the running version and identity. Release builds check GitHub's stable releases automatically after startup or on request, and show the latest and last confirmed versions with release links. A confirmed newer version adds orange indicators to Settings and the About row. Downloads are user-initiated and cancellable; the repository asset, size and published digest are verified, and only a matching per-user installation is offered Setup. Development, pull request and test builds never check. [#453](https://github.com/iricigor/fingvibe/pull/453), [#466](https://github.com/iricigor/fingvibe/pull/466).
- **Compact Settings:** Appearance, Devices and Scheduling start as collapsed sections with live one-line summaries of the current choices and schedule status. Expansion is remembered while the app runs, without changing saved preferences. [#453](https://github.com/iricigor/fingvibe/pull/453).
- **Database backups:** FingVibe keeps consistent local copies of its device inventory database, with seven recent copies plus one copy for each of the seven most recent days. Backups run shortly after startup and after successful scans. A new Tools page lists the copies and offers Back up now. [#357](https://github.com/iricigor/fingvibe/pull/357).
- **Steadier device status:** a device's Online or Offline status is kept across restarts, scan starts, pending checkpoints and interrupted scans; only a complete successful scan of the same network marks unresponsive devices Offline. Devices, Overview, Network and People/Rooms summaries agree. [#337](https://github.com/iricigor/fingvibe/pull/337).
- **LAN peer checkpoint:** each network troubleshooting run also checks one randomly chosen online device from the selected network's saved inventory, excluding this computer and the gateway. An empty pool is reported as unavailable with scan-first guidance, and a failing peer is inconclusive rather than marking a healthy network as broken. [#459](https://github.com/iricigor/fingvibe/pull/459).
- **Connected home icon:** the executable, window, taskbar, notifications, shortcuts and installer use the new Connected home icon, with tuned artwork for every size from 16 to 256 pixels instead of one downscaled image. [#496](https://github.com/iricigor/fingvibe/pull/496).

## Other user-facing changes

- **Device Details:** a responsive header with a compact Back action, aligned Overview and History sections, a compact usage-category editor, separate brand and detected vendor details, responsive service tiles and friendlier local observation dates. Back is now a single-line control at the left of the header on Device Details, every tool page and About, sized to match the tabs and growing with larger text. [#339](https://github.com/iricigor/fingvibe/pull/339), [#467](https://github.com/iricigor/fingvibe/pull/467).
- **Devices:** unrestricted filters use quieter labels while active choices stand out, filter titles are shorter, and Status choices show colored dots for Online, Offline, Unknown and Fing Only. Usage categories appear as compact colored badges with a 120-pixel default column; manual overrides keep their pin and only provisional automatic categories show an info icon. [#457](https://github.com/iricigor/fingvibe/pull/457), [#364](https://github.com/iricigor/fingvibe/pull/364).
- **Activity grids:** diagonal hatching is gone from Network, Device History and Person equipment activity. Missing evidence shows a muted `?` and partial weekday values a small trailing `?`, while activity fills, `N+` lower bounds and other evidence states stay distinct. [#472](https://github.com/iricigor/fingvibe/pull/472).
- **Layout:** pages share a tighter left inset with a softer navigation divider, and the Tools page arranges its cards in two equal columns. [#340](https://github.com/iricigor/fingvibe/pull/340), [#464](https://github.com/iricigor/fingvibe/pull/464).
- **Installation:** version 1.3 keeps the portable ZIP and the unsigned per-user Setup installer. Upgrade checks now cover a higher-build 1.2 installation, saved inventory, history and settings preservation, and subsequent downgrade rejection. [#496](https://github.com/iricigor/fingvibe/pull/496).

## Engineering and contributor improvements

- **Native validation:** the overloaded UI capture job is split into independent smoke, assignment and capture jobs, each within the 240-second budget, without removing checks or captures. A failed UI regression suite is retried once in a fresh process, with separate diagnostics; a second failure still blocks. [#474](https://github.com/iricigor/fingvibe/pull/474), [#494](https://github.com/iricigor/fingvibe/pull/494).
- **Router inspection tools:** standalone contributor tools inspect the client lists of a TP-Link EX220 router and Deco mesh units, with bounded retries, JSON export, exact-certificate approval and comparison against a FingVibe database. They are not part of the FingVibe application and never write to its data. [#388](https://github.com/iricigor/fingvibe/pull/388), [#402](https://github.com/iricigor/fingvibe/pull/402), [#410](https://github.com/iricigor/fingvibe/pull/410).
- **Icon pipeline:** editable SVG masters per size and a reproducible icon generator, with checks on frame sizes, transparency, padding and the frames embedded in the executable. Installer checks keep one previous-version upgrade case instead of separate 1.0 and 1.1 cases. [#496](https://github.com/iricigor/fingvibe/pull/496).

## Release scope and provenance

This feature summary starts immediately after the 1.2 version bump [#335](https://github.com/iricigor/fingvibe/pull/335), merged on 2026-11-11 at 21:59:57 UTC, and covers merged changes through the 1.3 preparation [#496](https://github.com/iricigor/fingvibe/pull/496). Individual release notes generated below it identify each release's additional merged changes.

In those 5 days (2026-11-11 to 2026-11-16 UTC), 49 pull requests were merged into main, including this preparation. 20 of them changed the application, its documentation or its build, test and contributor tooling and are summarized here. The other 29 changed only the agentic development loops (agent profiles, dispatch and coordination, automation and their trial fixtures), including nested [#342](https://github.com/iricigor/fingvibe/pull/342), and are intentionally omitted.

No application pull request in this range was abandoned or superseded. [#350](https://github.com/iricigor/fingvibe/pull/350) only records the abandoned idea of pale Connected home page backgrounds and transparent containers; no such background shipped, and the icon adoption above is separate.

Minor fixes: Activity views show their error state with Retry when stored analytics evidence is malformed, instead of failing ([#363](https://github.com/iricigor/fingvibe/pull/363)); clearer labels and wrapping in narrower Tools cards and tighter regression diagnostics in the contributing PRs linked above.
