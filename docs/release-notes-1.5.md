FingVibe 1.5 lets one physical device own several MAC addresses, adds a Network health page with opt-in background monitoring, service status and incident history, and turns updates into a short in-app flow.
It also gives every page one consistent header, Back control, section headings, icons and tabs, and adds a quick Light/Dark switch.

## Major changes

- **Linked devices:** link two saved device records that are the same physical device and edit their shared name, identification, Person, Room and usage category once. Devices shows a linked device as one row, using a representative MAC per network, and activity, history and Person equipment count it once: a response from any member wins. Add further MAC addresses, combine two linked devices, or unlink a MAC to restore its own values; vendor, family and model can stay separate per MAC. History lists combined scan observations and earlier MAC addresses, and tools such as ping target a real member address. [#596](https://github.com/iricigor/fingvibe/pull/596), [#600](https://github.com/iricigor/fingvibe/pull/600), [#604](https://github.com/iricigor/fingvibe/pull/604), [#601](https://github.com/iricigor/fingvibe/pull/601), [#608](https://github.com/iricigor/fingvibe/pull/608), [#610](https://github.com/iricigor/fingvibe/pull/610), [#612](https://github.com/iricigor/fingvibe/pull/612).
- **Network health:** Network troubleshooting becomes the **Network health** page, keeping the existing diagnostics, diagram, checkpoints and traceroute below a current-health card. An independent, persisted **Monitor network health** setting (off by default) runs a disclosed 60-second ping and DNS check in the background; a header dot beside **Network:** shows its state and opens the page. Completed checks produce verdicts against learned baselines, and confirmed problems become persisted incidents with history, bounded diagnostic evidence, retention and database-backup coverage. [#623](https://github.com/iricigor/fingvibe/pull/623), [#630](https://github.com/iricigor/fingvibe/pull/630), [#634](https://github.com/iricigor/fingvibe/pull/634), [#636](https://github.com/iricigor/fingvibe/pull/636), [#638](https://github.com/iricigor/fingvibe/pull/638), [#640](https://github.com/iricigor/fingvibe/pull/640).
- **Service status:** a Service status page, opened from Network health, shows official public status reports for six supported providers (Azure, AWS EC2 us-east-1, Google Workspace, Google Cloud, Cloudflare and GitHub), with clear cached, stale and unavailable states; malformed or failed feeds are never shown as healthy. [#629](https://github.com/iricigor/fingvibe/pull/629), [#632](https://github.com/iricigor/fingvibe/pull/632).
- **Simpler updates:** installed stable builds update with **Update now** from Settings or About, then a confirmation: **Restart now**, **When I close** or **Cancel**. FingVibe closes, installs the verified update and reopens, and reports the result on the next launch. Verified installers can download in the background (never on metered or unknown-cost connections) and are reverified before use. A scheduled update installs when FingVibe closes. About shows the available version's release notes as safe plain text. Portable copies keep the manual ZIP download. [#682](https://github.com/iricigor/fingvibe/pull/682), [#701](https://github.com/iricigor/fingvibe/pull/701), [#712](https://github.com/iricigor/fingvibe/pull/712), [#714](https://github.com/iricigor/fingvibe/pull/714), [#711](https://github.com/iricigor/fingvibe/pull/711).
- **Consistent page headers:** page icons, titles and Back stay fixed below the network bar while only the page body scrolls. Main, tool and detail pages share one header (optional Back, 48-DIP icon, title), and tool and detail pages use one quiet Back control that names its destination. Device, Person and Room details show the entity's own icon and name in that header. Device Details' Overview/History tabs use a new quiet segmented style at the right end of the header, wrapping beneath it in narrow windows; long device names truncate with the full name as a tooltip. [#674](https://github.com/iricigor/fingvibe/pull/674), [#716](https://github.com/iricigor/fingvibe/pull/716), [#722](https://github.com/iricigor/fingvibe/pull/722), [#723](https://github.com/iricigor/fingvibe/pull/723), [#725](https://github.com/iricigor/fingvibe/pull/725).

## Other user-facing changes

- **Section headings:** cards on Device Details, the main pages, Settings, People/Room details and the Network health, Speed test, Import from Fing and About tool pages open with one shared shaded heading band, section icon and divider. [#693](https://github.com/iricigor/fingvibe/pull/693), [#704](https://github.com/iricigor/fingvibe/pull/704), [#706](https://github.com/iricigor/fingvibe/pull/706).
- **Quick Light/Dark switch:** a footer shortcut above Settings switches between light and dark, keeping the chosen Standard, Warm/OLED or Colorful palette, and works in the compact rail and from the keyboard. [#680](https://github.com/iricigor/fingvibe/pull/680).
- **Icons:** People & rooms gets its own person-and-floor-plan icon, sidebar icons render at a consistent 24 DIP, and the pale halos around full-color page icons are removed. [#687](https://github.com/iricigor/fingvibe/pull/687), [#707](https://github.com/iricigor/fingvibe/pull/707), [#702](https://github.com/iricigor/fingvibe/pull/702).
- **Navigation affordances:** whole navigation cards use one trailing chevron, secondary navigation uses text links, and About's browser destinations show a separate external-link icon. Room map **Back** returns to where the map was opened (People & rooms, Tools or Network health). [#678](https://github.com/iricigor/fingvibe/pull/678), [#672](https://github.com/iricigor/fingvibe/pull/672).
- **Speed test:** the page groups into Test, Live measurement and Results cards, and the gauges and ratings use speed-quality colors that always come with text and become system colors in high contrast. [#676](https://github.com/iricigor/fingvibe/pull/676).
- **Responsiveness:** redundant inventory and usage refreshes after saves and unchanged live scan results are coalesced, without changing what is shown. [#648](https://github.com/iricigor/fingvibe/pull/648).
- **Documentation:** the README, user manual and guides are refreshed against v1.4.223 with 22 current native screenshots and GitHub Pages branding. [#651](https://github.com/iricigor/fingvibe/pull/651).
- **Installation:** version 1.5 keeps the portable ZIP and unsigned per-user Setup installer, with one higher-build 1.4-to-1.5 upgrade check, saved inventory/history/settings preservation and subsequent downgrade rejection. An installed 1.4 build's update check sees 1.5.x as newer. [#727](https://github.com/iricigor/fingvibe/pull/727).

## Engineering and contributor improvements

- **Regression coverage:** implementation PRs commit a structured regression manifest; CI derives path-based minimum selectors and runs them alongside full validation. [#665](https://github.com/iricigor/fingvibe/pull/665).
- **Installer and script validation:** installer lifecycle checks resolve the registered uninstaller and wait for each phase to finish, and standalone Full-validation scripts run in isolated PowerShell processes. [#586](https://github.com/iricigor/fingvibe/pull/586), [#644](https://github.com/iricigor/fingvibe/pull/644).
- **Documentation sync:** a documentation-sync agent reviews recent `main` changes and proposes focused documentation PRs. [#652](https://github.com/iricigor/fingvibe/pull/652).
- **Release identity:** release versions, tags, app metadata, Setup/ZIP names and release titles advance to 1.5 with the run-number build component. CI keeps its separate 0.0 identity, and release bodies prepend this summary while retaining automatically generated per-release notes. [#727](https://github.com/iricigor/fingvibe/pull/727).
